# Sprint_5 - Автотесты для сервиса Doska

##  Описание проекта

Проект содержит автоматизированные тесты для веб-сервиса [Doska](https://qa-desk.education-services.ru/). Тесты покрывают функциональность регистрации, авторизации, выхода из аккаунта и создания объявлений.

---

## 🧪 Структура тестов

Тесты организованы в тестовые классы внутри модулей для лучшей группировки по функциональности.

###  test_auth.py

| Класс | Тест | Что проверяет |
|-------|------|---------------|
| **TestRegistration** | `test_registration_user_success` | Успешная регистрация нового пользователя. Проверяет: переход на главную, отображение аватара и имени "User." |
| | `test_registration_with_wrong_email_error` | Регистрация с невалидным email (параметризованный тест: 6 вариантов). Проверяет: сообщение "Ошибка", красную рамку у полей Email, Пароль, Повторите пароль |
| | `test_registarion_with_already_registrated_user_error` | Регистрация с уже существующим email. Проверяет: сообщение "Ошибка", красную рамку у полей |
| **TestAuth** | `test_user_login_success` | Успешный вход существующего пользователя. Проверяет: переход на главную, имя "User.", аватар |
| | `test_user_logout_success` | Успешный выход. Проверяет: появление кнопки "Вход и регистрация", отсутствие имени и аватара |

###  test_ads.py

| Класс | Тест | Что проверяет |
|-------|------|---------------|
| **TestAds** | `test_ad_creation_by_unauthorized_user_error` | Создание объявления неавторизованным пользователем. Проверяет: появление модального окна с заголовком "Чтобы разместить объявление, авторизуйтесь" |
| | `test_ad_creation_by_authorized_user_success` | Создание объявления авторизованным пользователем. Проверяет: заполнение формы, публикацию, появление объявления в профиле |

##  Настройки драйвера

В `conftest.py` настроен Chrome с параметрами:

- `detach: True` — браузер не закрывается после теста без `driver.quit()`, полезно для отладки.
- Отключена проверка утечек паролей (предупреждение "Слитый пароль").

##  Запуск тестов

### Установка зависимостей

```bash
pip install -r requirements.txt

Запуск конкретного теста

bash

pytest -v tests/test_auth.py::TestRegistration::test_registration_user_success

Запуск тестов из конкретного файла

bash

pytest -v tests/test_auth.py
pytest -v tests/test_ads.py

   Настройка окружения

Убедитесь, что установлены:

    Python 3.14+

    Браузер Chrome

    ChromeDriver (совместимый с версией Chrome)

Установите зависимости:
bash

pip install selenium pytest

Примечания

    Для генерации уникального email используется функция generate_email() из helpers.py, которая вызывается через фикстуру email().

    Тесты используют явные ожидания (WebDriverWait) вместо time.sleep().

    Браузер автоматически закрывается после каждого теста благодаря использованию yield в фикстуре driver.

    Пользователь testemail@mail.ru должен существовать в системе для тестов логина и логаута.
